LinkedLife

TYPESCRIPT · REACT · VITE

A satirical LinkedIn life-sim. You cold-message strangers, hold conversations, sit interviews, and climb a career ladder while your network tries to eat you.

A local classifier buckets typed messages into a tone, and that bucket alone determines the stat and relationship consequences. An LLM, if configured, only writes flavor text - never game logic. The game is fully playable and deterministic with zero API calls.

The engine is deterministic and seeded, which is what makes headless bot playthroughs possible: a bot drives the real store for thousands of turns and asserts invariants after every action, catching balance regressions that type checking cannot.
