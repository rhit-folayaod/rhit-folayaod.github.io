Resume Tailor

PYTHON · FASTAPI · LATEX

A web app and CLI that ranks pre-written resume bullets against a job posting and compiles a tailored PDF via LaTeX/Tectonic.

The design constraint that matters: it cannot invent resume content. Printed text only comes from a validated store. An optional LLM rerank step can only reorder existing bullet IDs - it never emits new bullet text. Job-post parsing extracts required and preferred skills for scoring, not for printing.

The same codebase runs locally against a YAML store or hosted with Supabase Auth and Postgres. FastAPI serves a plain HTML/JS UI; Tectonic compiles the PDF inside Docker on Fly.io.
