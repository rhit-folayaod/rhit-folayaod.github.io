Two-Player Jetpack Joyride

PYTHON · PYGAME · NI

A two-player split-screen endless flyer in pygame. Holding a button fires a jetpack; letting go drops you. Two players share one screen, one lane each, and race the same obstacle course until both crash - whoever flies furthest wins.

Physical buttons are wired into an NI mioDAQ via nidaqmx. A background thread polls the DAQ so driver reads never stall the 60fps game loop; LEDs mirror each player's button. When no hardware is present it falls back to the keyboard automatically, which is how it was developed. During a hardware round the keyboard is ignored so a bystander can't steal control.

Self-initiated during my Emerson/NI internship, not an assigned project, and built with Cursor and Claude Code. Both lanes share a seed from a vetted pool so the courses are identical and skill is the only variable.
