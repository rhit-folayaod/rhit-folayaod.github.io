# Site audio

The background music is not a file. It is an original ambient loop composed for
this site and synthesized in the browser with the Web Audio API
(`assets/js/music.js`): sine-wave pad chords plus a triangle-wave melody in
C major pentatonic. No samples, recordings, or game soundtracks are used.

License: CC0 1.0 (public domain dedication), https://creativecommons.org/publicdomain/zero/1.0/
Author: Timi Folayan (site owner), 2026.

Music is off by default; the speaker button (taskbar on the desktop, bottom
corner inside a game) turns it on or off, and the choice is saved in localStorage.
